# AlphaTech-Analyzer

## Objetivo del proyecto

**AlphaTech-Analyzer** es un proyecto de análisis cuantitativo orientado al estudio del comportamiento financiero de un conjunto de empresas tecnológicas (Tech30) a lo largo del periodo **2018–2024**.

El objetivo general del proyecto es **explorar, analizar y modelar datos financieros** utilizando técnicas de **estadística, análisis de datos y econometría**, con el fin de:

- Comprender la relación entre las empresas tecnológicas y el mercado.
- Analizar métricas clave como **retornos, volatilidad, correlación y volumen**.
- Extraer conclusiones estadísticas que permitan interpretar patrones y diferencias entre empresas.
- Apoyar la toma de decisiones y la presentación de resultados mediante **visualizaciones y diagnósticos estadísticos**.

El proyecto está diseñado con un enfoque **reproducible y modular**, permitiendo extender el análisis a nuevos modelos o periodos de estudio.

---

## Notebooks desarrollados

El análisis se organiza en notebooks que siguen un flujo lógico:

### 1. Preparación y exploración de datos
- Importación de librerías y configuración del entorno.
- Carga y validación de datasets financieros.
- Transformaciones temporales y cálculo de métricas básicas.

### 2. Análisis estadístico y modelado
- Estudio de relaciones entre variables financieras.
- Estimación de modelos estadísticos y econométricos.
- Evaluación de supuestos y calidad del ajuste.

### 3. Análisis por empresa
- Modelos y métricas calculadas a nivel individual.
- Comparación entre empresas del sector tecnológico.

### 4. Visualización y diagnóstico de resultados
- Gráficos exploratorios y explicativos.
- Diagnósticos estadísticos y análisis de residuos.
- Preparación de salidas para reportes y presentaciones.
